# Carpeta `yaml`

## 🎯 Objetivo
Aquí se almacenan los archivos `.yaml` generados automáticamente mediante la clase `GeneradorYAML`.

## 📂 Contenido
- Archivos YAML que representan listas originalmente hardcodeadas en `datos_a_convertir.py`.
- Script `generando_yaml.py` con ejemplo comentado de cómo ejecutar la conversión.

## 📝 Nota
Los archivos de esta carpeta **no deben editarse manualmente**.  
Si se necesita modificar los datos, se debe actualizar el diccionario en `datos_a_convertir.py` y volver a ejecutar la clase `GeneradorYAML`.
